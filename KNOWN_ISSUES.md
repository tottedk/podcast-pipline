# Known issues

## Release validation

Technical v1.14 / content v2.6: short tests only. No new full episode has been rendered on this release. A complete passing episode is still a release gate, and it needs an explicit decision before anyone runs it. Existing finished audio is not regenerated by these patches.

`python tests/test_md_clean.py` (9 tests) and `python tests/test_v112.py` (20 tests) pass on this tree. There is no other linter or test config in the repository. `tests/test_v112.py` expected Carter's mapped tempo to be 0.90 after `drama3_tempo.json` had already been set to 0.86; the assertion now expects 0.86. That failure existed on `main` (`b352181`) before the sync.

`templates/code_v1.14/SHA256SUMS.txt` covers the eight files that were in the drop. `run_episode.ps1 -DryRun` still prints the mix gate as "145-175 wpm". The gate that actually fails the run is `qc_mix.py`: guests 145–175, host 145–190, no intra-line pause over 1.5 seconds.

## Speech

- Carter's fixed tempo 0.86 produced about 177–180.5 words per minute in full episodes, above the old 175 host ceiling. The per-segment plan (target 156, bounds 0.72–0.95) is implemented in `d3_pace.py` and covered by `tests/test_v112.py`, and `drama3_tempo.json` does not use it. A short test of that plan measured about 162–165 wpm. Large atempo corrections can smear the sound. Listening approval is still open. The host ceiling is now 190 so the fast Carter take can pass.
- Flat delivery: sentence-aware chunks, delivery directions (`drama3_directions.json`), and a pitch-variation gate reduce resets. After two retries the best flat take is kept and flagged. It is not certified as natural speech. The real-audio retry path was not triggered in the short test.
- Previous-take continuity is not enabled. Using it would reload the model per chunk. That overhead was estimated at about one extra hour per episode.
- `tools/start_brief.ps1` requires Carter as host and refuses Maya, Declan, Alice, Mary, and Hugh. `pick_cast.py` still has Elliot, Hugh, and Lachlan in the random pool (Maya and Declan are out of the pool unless overridden; Alice, Mary, and Thomas are never accepted). Notes say to leave Elliot and Lachlan out of production casts. That is not a ban enforced by `pick_cast.py`. The Episode desk is a separate repository; its UI defaults were not updated here and were not re-tested.
- VibeVoice-7B is only the fallback (`-Engine 7b`). Its roster, credits, and the exact TTS weight license still need a check on the PC before any episode is published with that engine.

## Content and QC

- Facts, quotes, fictional guest anecdotes, and sources need a human check. A humanity dial does not make an anecdote true.
- Spoken labels, duplicate endings, and part-join echoes have guards. Those guards are not a proof that a production run is clean.
- An episode that already shipped can still contain issues that a later patch does not repair.

## Desk

The Windows spawn-flags bug, and the false HTTP 500 after a successful short launcher exit, were fixed on the PC in October. The desk code is not in this repository. Preserve those regression tests in the desk repo. The desk reads config at startup and must be restarted to pick up changes. A local "ready" flag is not proof of a right to use a voice.
